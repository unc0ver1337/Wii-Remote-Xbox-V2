# Wii Remote Xbox V2

Wii Remote Plus (MotionPlus) + Nunchuk → виртуальный Xbox 360 для Windows.

## Управление (v2.3)

- Обычный стик Nunchuk → левый стик Xbox. Его направления сохранены.
- Акселерометр Nunchuk не используется для управления.
- Повороты Wii Remote → правый стик относительно центра. Обе оси датчика развёрнуты по результатам проверки пользователя. По умолчанию полное отклонение достигается при повороте на 30°.
- Удерживайте **Home**, направьте Wii Remote в удобный центр и отпустите. Правый стик во время удержания нейтрален. Стабильные показания уточняют смещение гироскопа.
- Wii Remote **1 → Start**, **2 → Back**: срабатывают при нажатии и удерживаются до отпускания. Комбинация 1+2 больше не выполняет центровку.
- B → RT, A → RB, + → Y, − → X; Nunchuk C → LB, Z → LT.
- Крестовина не назначена. Автоматических L3/R3 нет.

## Установка и запуск

1. Установите Python 3 с launcher `py` и [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
2. Подключите Wii Remote Plus по Bluetooth средствами Windows и подключите Nunchuk.
3. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`.
4. Задайте центр через Home. Блокирующей начальной калибровки нет.
5. Остановка: Ctrl+C. Принудительно — `stop_wii_xbox_bridge.cmd`.

Перед запуском остановите другие экземпляры моста и программы, использующие Wii Remote.
Параметры чувствительности: `run_wii_xbox_bridge.cmd --full-angle 40 --deadzone 2`.
Направления гироскопа при необходимости можно изменить через `--yaw-sign -1` и `--pitch-sign -1`.

## Технические сведения

MotionPlus работает в Nunchuk passthrough mode (0x05), формат отчёта 0x37, данные расширения начинаются с байта 16. Пакеты гироскопа и Nunchuk обрабатываются отдельно. Медианный фильтр, сглаживание скоростей и отбрасывание повреждённых пакетов подавляют рывки. При потере гироскопа правый стик сбрасывается, программа пытается восстановить поток.

Это управление ориентацией без внешнего ориентира; возможен дрейф, исправляемый центровкой Home. Начальный ноль определяется в фоне по пяти стабильным пакетам.

Протокол: [WiiBrew MotionPlus](https://wiibrew.org/wiki/Wiimote/Extension_Controllers/Wii_Motion_Plus), [wiiuse](https://github.com/wiiuse/wiiuse/blob/master/src/motion_plus.c).

Проверка: `python test_bridge.py`. Тесты проверяют фильтрацию, разбор пакетов, Nunchuk, немедленные нажатия и удержание 1/2, независимую центровку Home и восстановление потока. Проверки программы не заменяют проверку направлений и ощущений на физическом устройстве.
