# Wii Remote Xbox V2 — v2.14

Wii Remote Plus + Nunchuk → виртуальный Xbox 360 для Windows.

## Управление

- Стик Nunchuk → левый стик Xbox; гироскоп Wii Remote → правый стик.
- **Нажатие 1 или 2** сразу задаёт новый центр направления. Удержание не блокирует движения. Кнопки не калибруют датчик и не отправляют Start/Back.
- Автоцентрирование по таймеру отключено. Автоподстройка нуля гироскопа в покое сохранена; коррекция акселерометром Wii Remote отключена.
- Крестовина ↑ / → / ↓ / ← → Y / B / A / X.
- − → Back, + → Start, Home → Xbox Guide.
- Wii A / B → RB / RT; Nunchuk C / Z → LB / LT.
- Акселерометр Nunchuk отключён, автоматических L3/R3 нет.

## Запуск

Установите Python 3 с launcher `py` и [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases), подключите Wii Remote по Bluetooth и присоедините Nunchuk. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`. Остановка — Ctrl+C или `stop_wii_xbox_bridge.cmd`. Не запускайте одновременно несколько мостов или другие программы для Wii Remote.

Полное отклонение правого стика при 8°, мёртвая зона 0.35°. Чувствительность: `run_wii_xbox_bridge.cmd --full-angle 10 --deadzone 0.5`. Yaw ограничен ±12.5°. Коррекция акселерометром отключена.

## Проверка

`python test_bridge.py` проверяет фильтрацию гироскопа, обработку пакетов, раскладку, ручную центровку и восстановление потока. Это не заменяет проверку на физическом устройстве.

## Прямой гироскоп без сглаживания

Убраны медианный фильтр движения, экспоненциальное сглаживание скорости, порог скорости 1°/с и подмешивание акселерометра. Каждый корректный пакет напрямую обновляет угол. История пяти пакетов используется только для автоматической оценки нуля датчика. Защита от повреждённых пакетов сохранена. Это может сделать шум и дрейф заметнее; 1/2 задают новый центр.
