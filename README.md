# Wii Remote Xbox V2 — v2.16

Wii Remote Plus + Nunchuk → виртуальный Xbox 360 для Windows.

## Правый стик: скорость вращения

Вращаете пульт — правый стик отклоняется. Останавливаете — возвращается в ноль на следующем корректном пакете гироскопа. Чем быстрее вращение, тем сильнее отклонение. Угол не накапливается, акселерометр не используется. Нет медианного фильтра движения, плавного усреднения или задержки возврата.

Полное отклонение при 90°/с. Небольшой порог подавляет шум: движение включается выше 2°/с, выключается при снижении до 1°/с. Это предотвращает переключение вокруг порога без сглаживания движения. Защита от повреждённых пакетов сохранена; отсутствие корректных данных более 50 мс обнуляет правый стик.

Автоподстройка нуля гироскопа в покое сохранена. Кнопки 1/2 не назначены и не влияют на правый стик или калибровку. В режиме скорости центровка не нужна.

## Раскладка

- Обычный стик Nunchuk → левый стик, направления сохранены.
- Гироскоп Wii Remote → правый стик, направления сохранены.
- Крестовина ↑ / → / ↓ / ← → Y / B / A / X.
- − → Back, + → Start, Home → Xbox Guide.
- Wii A / B → RB / RT; Nunchuk C / Z → LB / LT.
- Акселерометр Nunchuk не управляет стиком; автоматических L3/R3 нет.

## Запуск

Установите Python 3 с launcher `py` и [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases), подключите Wii Remote по Bluetooth и присоедините Nunchuk. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`. Остановка — Ctrl+C или `stop_wii_xbox_bridge.cmd`. Не запускайте несколько экземпляров и другие программы для Wii Remote одновременно.

Ещё чувствительнее: `run_wii_xbox_bridge.cmd --full-speed 60`. Менее чувствительно: `--full-speed 120`. Порог шума: `--speed-deadzone 2`. Старые параметры углового режима `--full-angle` / `--deadzone` больше не используются.

Проверка: `python test_bridge.py`. Проверяются немедленная смена направления и остановка, шумовая зона, разбор пакетов, кнопки и восстановление потока. Физические ощущения и отсутствие дрожания в игре требуют проверки на устройстве.
