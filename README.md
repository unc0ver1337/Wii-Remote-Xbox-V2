# Wii Remote Xbox V2

Wii Remote Plus (MotionPlus) + Nunchuk → виртуальный Xbox 360 для Windows.
Отдельная экспериментальная V2; первая версия остаётся в своём репозитории.

## Управление

- Nunchuk: обычный левый стик, C → LB, Z → LT.
- Поворот Wii Remote вправо/влево и вверх/вниз → правый стик относительно заданного центра. Поворот на 30° даёт полное отклонение; возврат к центральному направлению возвращает стик в ноль.
- Удерживайте **1+2 одновременно**, направьте пульт в удобный центр и отпустите. Во время удержания правый стик нейтрален.
- Автоматические L3/R3 убраны. LT/RT сохранены: это триггеры, а не нажатия стиков.
- B → RT, A → RB, + → Y, − → X. Отдельные 1/2 → Start/Back при отпускании; комбинация 1+2 их подавляет.
- Крестовина больше не управляет правым стиком; пока не назначена. Остальной ремаппинг отложен.
- Режим normal, меню инверсии и отдельного батника inverted нет.

## Запуск

1. Установите Python 3 с launcher `py` и драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
2. Подключите Wii Remote Plus по Bluetooth средствами Windows, подключите Nunchuk.
3. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`.
4. После сообщения Ready задайте центр сочетанием 1+2. Начальной калибровки с удержанием пульта нет.
5. Остановка: Ctrl+C; принудительно — `stop_wii_xbox_bridge.cmd`.

Перед запуском остановите V1, Dolphin и другие программы, использующие этот пульт. Одновременно запускайте только один экземпляр моста.

Параметры: `run_wii_xbox_bridge.cmd --full-angle 40 --deadzone 2`.
Если направление конкретной оси на вашем устройстве противоположное, доступны `--yaw-sign -1` и `--pitch-sign -1`.

## Реализация и проверка

MotionPlus активируется в Nunchuk passthrough mode (0x05); гироскоп и Nunchuk разбираются как разные пакеты. Угловые скорости интегрируются в кватернион; направление пульта преобразуется в оси правого стика. Смещение датчика читается из заводских данных (если они недоступны, используется номинальное значение), порог скорости подавляет мелкий шум. При потере потока виртуальный контроллер сбрасывается.

Протокол: [WiiBrew MotionPlus](https://wiibrew.org/wiki/Wiimote/Extension_Controllers/Wii_Motion_Plus), [wiiuse implementation](https://github.com/wiiuse/wiiuse/blob/master/src/motion_plus.c).

Это управление ориентацией, а не отслеживание положения руки. Без внешнего ориентира возможен дрейф, особенно по горизонтали: используйте 1+2. Масштаб гироскопа приближённый; чувствительность регулируется через full-angle.

Автоматические тесты используют синтетические HID-пакеты. Физическая работа MotionPlus, направления осей и ощущения в игре требуют проверки на устройстве; успешные тесты этого не подтверждают.
