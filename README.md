# Wii Remote Xbox V2

Wii Remote Plus (MotionPlus) + Nunchuk → виртуальный Xbox 360 для Windows.

## Управление (v2.5)

| Вход | Xbox 360 |
| --- | --- |
| Крестовина вверх / вправо / вниз / влево | Y / B / A / X |
| − / + | Back / Start |
| Home | Xbox Guide |
| Wii Remote A / B | RB / RT |
| Nunchuk C / Z | LB / LT |
| Стик Nunchuk | Левый стик, направления сохранены |
| Гироскоп Wii Remote | Правый стик, направления сохранены |
| 1 / 2 | Не назначены |

Кнопки 1/2 не выполняют никаких действий. Смещение гироскопа автоматически уточняется по стабильным показаниям при малой скорости. Акселерометр Nunchuk не управляет стиком. Автоматических L3/R3 нет.

## Установка и запуск

1. Установите Python 3 с launcher `py` и [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
2. Подключите Wii Remote Plus по Bluetooth средствами Windows и подключите Nunchuk.
3. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`.
4. Запуск определяет исходное направление автоматически. Блокирующей начальной калибровки нет.
5. Остановка: Ctrl+C. Принудительно — `stop_wii_xbox_bridge.cmd`.

Перед запуском остановите другие экземпляры моста и программы, использующие Wii Remote.
Параметры чувствительности: `run_wii_xbox_bridge.cmd --full-angle 40 --deadzone 2`.
Направления гироскопа при необходимости можно изменить через `--yaw-sign -1` и `--pitch-sign -1`.

## Технические сведения

MotionPlus работает в Nunchuk passthrough mode (0x05), формат отчёта 0x37, данные расширения начинаются с байта 16. Пакеты гироскопа и Nunchuk обрабатываются отдельно. Медианный фильтр, сглаживание скоростей и отбрасывание повреждённых пакетов подавляют рывки. При потере гироскопа правый стик сбрасывается, программа пытается восстановить поток.

Это управление ориентацией без внешнего ориентира; абсолютная горизонтальная ориентация неизвестна, поэтому горизонтальный угол ограничивается диапазоном стика. Начальный ноль определяется в фоне по пяти стабильным пакетам.

Протокол: [WiiBrew MotionPlus](https://wiibrew.org/wiki/Wiimote/Extension_Controllers/Wii_Motion_Plus), [wiiuse](https://github.com/wiiuse/wiiuse/blob/master/src/motion_plus.c).

Проверка: `python test_bridge.py`. Тесты проверяют фильтрацию, разбор пакетов, Nunchuk, раскладку ABXY/Back/Start/Guide, отсутствие назначений 1/2 и автоматическую подстройку нуля и восстановление потока. Проверки программы не заменяют проверку направлений и ощущений на физическом устройстве.

## Резкость гироскопа

По умолчанию полное отклонение правого стика достигается при повороте на 15° (ранее 30°); мёртвая зона 0.35° (ранее 1.5°). Сглаживание скорости уменьшено с 25 до 6 мс, медианное окно движения — с пяти до трёх пакетов. Проверка стабильности нуля по-прежнему использует пять пакетов, защита от повреждённых данных сохранена. Мелкие движения теперь заметнее. Ещё чувствительнее: `run_wii_xbox_bridge.cmd --full-angle 10 --deadzone 0.2`.

## Автоматическая коррекция по принципу Dolphin (v2.8)

Таймер неподвижности удалён. Повороты гироскопа дополняются направлением силы тяжести из **акселерометра Wii Remote**: это плавно исправляет дрейф наклона. Акселерометр Nunchuk не задействован. Горизонтальный угол ограничивается диапазоном правого стика: после достижения края обратный поворот сразу уводит стик от края, без накопления лишнего угла.

Реализация самостоятельная, адаптирована под Xbox-стик по принципам [Dolphin EmulateIMUCursor](https://github.com/dolphin-emu/dolphin/blob/master/Source/Core/Core/HW/WiimoteEmu/Dynamics.cpp). Это не точная копия поведения Dolphin. Коррекция использует первоначальное направление силы тяжести как ориентир и приближённый ноль акселерометра; качество на физическом устройстве требует проверки. При неподвижной руке горизонтальный стик не обнуляется по таймеру: без внешнего ориентира абсолютный yaw неизвестен.

## Стандартные параметры Dolphin

Total Yaw — 25° (ограничение ±12.5°), Accelerometer Influence — 2% за шаг 5 мс, с пересчётом для фактической частоты пакетов. Для Xbox полное отклонение по умолчанию достигается при 12.5°. Таймер возврата в ноль отсутствует, 1/2 не назначены. Мёртвая зона Xbox 0.35° и фильтр гироскопа — собственные параметры моста; адаптация под Xbox не воспроизводит Dolphin побитно.
