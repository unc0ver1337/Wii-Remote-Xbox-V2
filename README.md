# Wii Remote Xbox V2

Wii Remote Plus (MotionPlus) + Nunchuk → виртуальный Xbox 360 для Windows.

## Управление (v2.4)

| Вход | Xbox 360 |
| --- | --- |
| Крестовина вверх / вправо / вниз / влево | Y / B / A / X |
| − / + | Back / Start |
| Home | Xbox Guide |
| Wii Remote A / B | RB / RT |
| Nunchuk C / Z | LB / LT |
| Стик Nunchuk | Левый стик, направления сохранены |
| Гироскоп Wii Remote | Правый стик, направления сохранены |
| Нажатие 1 **или** 2 | Только центровка направления |

1/2 центрируют при нажатии; удержание не фиксирует стик в нуле. Центровка сбрасывает только направление, не калибрует гироскоп. Смещение гироскопа автоматически уточняется по стабильным показаниям при малой скорости; для этого не нужны кнопки. Очень медленное равномерное вращение датчик может принять за покой. Акселерометр Nunchuk не управляет стиком. Автоматических L3/R3 нет.

## Установка и запуск

1. Установите Python 3 с launcher `py` и [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
2. Подключите Wii Remote Plus по Bluetooth средствами Windows и подключите Nunchuk.
3. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`.
4. Задайте центр нажатием 1 или 2. Блокирующей начальной калибровки нет.
5. Остановка: Ctrl+C. Принудительно — `stop_wii_xbox_bridge.cmd`.

Перед запуском остановите другие экземпляры моста и программы, использующие Wii Remote.
Параметры чувствительности: `run_wii_xbox_bridge.cmd --full-angle 40 --deadzone 2`.
Направления гироскопа при необходимости можно изменить через `--yaw-sign -1` и `--pitch-sign -1`.

## Технические сведения

MotionPlus работает в Nunchuk passthrough mode (0x05), формат отчёта 0x37, данные расширения начинаются с байта 16. Пакеты гироскопа и Nunchuk обрабатываются отдельно. Медианный фильтр, сглаживание скоростей и отбрасывание повреждённых пакетов подавляют рывки. При потере гироскопа правый стик сбрасывается, программа пытается восстановить поток.

Это управление ориентацией без внешнего ориентира; возможен дрейф, исправляемый центровкой 1 или 2. Начальный ноль определяется в фоне по пяти стабильным пакетам.

Протокол: [WiiBrew MotionPlus](https://wiibrew.org/wiki/Wiimote/Extension_Controllers/Wii_Motion_Plus), [wiiuse](https://github.com/wiiuse/wiiuse/blob/master/src/motion_plus.c).

Проверка: `python test_bridge.py`. Тесты проверяют фильтрацию, разбор пакетов, Nunchuk, раскладку ABXY/Back/Start/Guide, отдельную центровку 1/2 и автоматическую подстройку нуля и восстановление потока. Проверки программы не заменяют проверку направлений и ощущений на физическом устройстве.
