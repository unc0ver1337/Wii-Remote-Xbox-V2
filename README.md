# Wii Remote Xbox V2

Wii Remote Plus (MotionPlus) + Nunchuk → виртуальный Xbox 360 для Windows.
Отдельная экспериментальная V2; первая версия остаётся в своём репозитории.

## Управление

- Nunchuk: обычный стик **и наклоны** управляют левым стиком Xbox; C → LB, Z → LT. Ввод суммируется с ограничением до диапазона стика. Наклон 30° даёт полное отклонение, мёртвая зона — 5°.
- Поворот Wii Remote вправо/влево и вверх/вниз → правый стик относительно заданного центра. Поворот на 30° даёт полное отклонение; возврат к центральному направлению возвращает стик в ноль.
- Удерживайте **1+2 одновременно**, направьте пульт в удобный центр и отпустите. Во время удержания правый стик и вклад наклона Nunchuk нейтральны; обычный стик Nunchuk продолжает работать. Центр наклонов задаётся положением Nunchuk при отпускании 1+2.
- Автоматические L3/R3 убраны. LT/RT сохранены: это триггеры, а не нажатия стиков.
- B → RT, A → RB, + → Y, − → X. Отдельные 1/2 → Start/Back при отпускании; комбинация 1+2 их подавляет.
- Крестовина больше не управляет правым стиком; пока не назначена. Остальной ремаппинг отложен.
- Режим normal, меню инверсии и отдельного батника inverted нет.

## Запуск

1. Установите Python 3 с launcher `py` и драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
2. Подключите Wii Remote Plus по Bluetooth средствами Windows, подключите Nunchuk.
3. Запустите `setup.cmd`, затем `run_wii_xbox_bridge.cmd`.
4. После сообщения Ready задайте центр сочетанием 1+2. Начальной калибровки с удержанием пульта нет.
5. Остановка: Ctrl+C; принудительно — `stop_wii_xbox_bridge.cmd`.

Перед запуском остановите V1, Dolphin и другие программы, использующие этот пульт. Одновременно запускайте только один экземпляр моста.

Параметры: `run_wii_xbox_bridge.cmd --full-angle 40 --deadzone 2`.
Если направление конкретной оси на вашем устройстве противоположное, доступны `--yaw-sign -1` и `--pitch-sign -1`.

## Реализация и проверка

MotionPlus активируется в Nunchuk passthrough mode (0x05); гироскоп и Nunchuk разбираются как разные пакеты. Угловые скорости интегрируются в кватернион; направление пульта преобразуется в оси правого стика. Ноль датчика определяется в фоне по пяти стабильным пакетам, без блокирующей начальной калибровки. Медианный фильтр подавляет одиночные выбросы, сглаживание скорости уменьшает рывки, небольшой порог подавляет шум. Во время определения нуля правый стик остаётся нейтральным. Формат отчёта 0x37: расширение начинается с байта 16. Пакеты с некорректной меткой и предельными значениями АЦП отбрасываются. При потере гироскопа правый стик сбрасывается; через 3 секунды программа пробует восстановить поток без завершения процесса.

Протокол: [WiiBrew MotionPlus](https://wiibrew.org/wiki/Wiimote/Extension_Controllers/Wii_Motion_Plus), [wiiuse implementation](https://github.com/wiiuse/wiiuse/blob/master/src/motion_plus.c).

Это управление ориентацией, а не отслеживание положения руки. Без внешнего ориентира возможен дрейф, особенно по горизонтали: используйте 1+2. Масштаб гироскопа приближённый; чувствительность регулируется через full-angle.

При удержании 1+2 стабильные показания также уточняют нулевое смещение датчика: направьте пульт в центр и удержите неподвижно около 0.1 секунды.

Автоматические тесты используют синтетические HID-пакеты и захваченные ошибочные пакеты Nunchuk; проверяются удержание C и потеря гироскопа без вылета. На подключённом устройстве подтверждено получение раздельных пакетов MotionPlus и Nunchuk в формате 0x37. Физическая работа MotionPlus, направления осей и ощущения в игре требуют проверки на устройстве; успешные тесты этого не подтверждают.

Проверка фильтра v2.1: воспроизведён записанный 12-секундный поток (1525 гироскопических пакетов, 133 повреждённых пакета отвергнуты); максимальное отклонение правого стика при воспроизведении — 0. Это проверка конкретной записи, а не подтверждение качества управления при любых движениях.

## Акселерометр Nunchuk (v2.2)

Читаются все три оси акселерометра с учётом формата MotionPlus passthrough. Наклоны вычисляются по направлению силы тяжести, сглаживаются; сильные ускорения вне допустимого диапазона игнорируются. Исходный центр задаётся первым корректным пакетом, новый — удержанием 1+2. Во время центровки держите Nunchuk в удобном нейтральном положении. Это управление наклонами; перемещение руки без наклона не отслеживается.

Чувствительность: `run_wii_xbox_bridge.cmd --tilt-angle 40 --tilt-deadzone 7`. Физическое направление осей и ощущения от совмещённого управления требуют проверки пользователем.
